# ASC Agent

A lightweight Python agent scaffold for task planning and execution, plus a small set of exercise problems.

## Features

- Generates a structured action plan from a natural-language task
- Tracks execution status and a brief summary
- Includes a small CLI for running tasks from the command line

## Quick start

```bash
python -m agent.cli --task "Create a feature brief for a new workflow"
```

## Running tests

```bash
python -m unittest discover -s tests -v
```

## Exercises

Problem statements live under the `ASC/` directory (e.g. `ASC/ASC54. 温室里的英雄与背包`).
